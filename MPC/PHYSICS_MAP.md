## 0. 한 장 요약 — 근사의 사다리

```
[진짜 물리]  35 dof 다물체 + 접촉 상보성 + 마찰 + 액추에이터 동역학
     ↓ ①  다물체 → 단일 강체 (SRB)            ← 제일 큰 근사. 다리 43% 질량 무시
     ↓ ②  회전 비선형 → 선형 (작은 각 + 정상세차 무시)
     ↓ ③  접촉 상보성 → 고정 스케줄 + 볼록 제약
     ↓ ④  마찰 원뿔 → 사각뿔
     ↓ ⑤  연속시간 → 0.05 s ZOH 이산
     ↓ ⑥  무한 지평 → 16스텝(0.8 s) + 종단비용 없음
[우리 MPC]   13상태 12입력 QP, 100 Hz
     ↓ ⑦  wrench → 관절토크 (준정적 + WBC-lite 부분보상)
[MuJoCo 진짜 로봇]
```
**①과 ⑦의 간극이 현재 성능 한계의 대부분.** ②~⑥은 지금 병목이 아님.

## 1. 진짜 물리 (MuJoCo가 푸는 것)

```
M(q) q̈ + h(q, q̇) = Sᵀτ + Σ_c J_cᵀ f_c        (35 dof: 자유 베이스 6 + 관절 29)
                    0 ≤ f_z ⊥ (침투깊이) ≥ 0   (접촉 상보성)
                    ‖f_xy‖ ≤ μ f_z            (마찰 원뿔)
```
- `M`: 35×35 **밀집** 질량행렬 — 이 밀집성이 나중에 핵심이 된다(§7)
- `h`: 중력 + 코리올리 + 원심
- 접촉: 발당 구 4개 × 2발 = 8점, MuJoCo가 매 스텝 LCP로 풀어줌

**우리가 손대지 않은 것**: 이건 시뮬레이터가 하는 일이고 우리 컨트롤러는 이 식을
**풀지 않는다**. 다만 `qfrc_bias`(= h)만 MuJoCo에서 빌려 쓴다 (§7).

## 2. 근사 ① 다물체 → 단일 강체 (SRB) ★ 제일 큰 근사

### 무엇을 버렸나
로봇 전체를 **막대기 하나**로 본다. 다리·팔의 질량과 관성은 "몸통에 붙어 있다"고
치고, **다리가 따로 움직이는 효과를 전부 무시**한다.

```
p̈ = (1/M) Σ F_i − g ẑ                 (병진)
d(Iω)/dt = Σ (r_i × F_i + m_i)        (회전)
```

### 이 로봇에서 얼마나 나쁜 근사인가 — 실측
| 부위 | 질량 | 비율 |
|---|---|---|
| 전체 | 33.34 kg | 100% |
| **다리 (12링크)** | **14.37 kg** | **43.1%** ← Cheetah 3 는 10%. MIT Humanoid 도 **43.7%로 동일** — 단 무릎 아래가 0.63 vs 우리 2.61 kg (MPC_NOTES 20절) |
| 팔 (14링크) | 7.04 kg | 21.1% (현재 **놀고 있음** — §11) |
| 몸통+골반 | ~11.9 kg | ~36% |

> ⚠ 정정: 이전 문서들에서 "다리 30%"라 썼는데 **실측 43%**다. Di Carlo 가
> "다리 질량 10%라 SRB 가 합리적"이라 한 것과 **4배 차이**. 우리가 겪은 모든
> massless-leg 문제의 크기가 여기서 설명된다.

### 이 근사가 새는 곳 (증상)
1. **정적 중력조차 틀림** — `τ = −Jᵀf`(순수 SRB)로는 서지도 못했다. 무릎에서 4.6 N·m,
   힙 피치는 **부호까지 반대**(−2.79 vs +1.77). → §7 의 `qfrc_bias` 로 메움.
2. **swing 반작용** — 다리를 던지면 몸통이 반대로 밀림/돌아감. 0.3 m/s 에서 ~250 N,
   몸통 유효 28 kg 에 −5 m/s² 급. **속도 벽의 직접 원인** (격리 실험으로 확정:
   다리 질량 1/3 로 줄이면 0.3 m/s 완주, 원래 질량은 6.4 s 전도).
3. **Θ/ω 불일치** — §4 참조.

### 지금 상태
근사를 고친 게 아니라 **바깥에서 보상**한다: `qfrc_bias`(정적) + `M q̈_swing`(동적).
모델 자체는 여전히 SRB.

**"다리를 모델에서 빼면(상체만 SRB)?" — 실험함 (MPC_NOTES 21절, 2026-09-15).**
결론: 우리 구성에선 전 영역에서 baseline 에 진다 (직진 0.3: 20 s ✓ vs 4~13 s).
전신 L·전신 I 조합은 다리 반작용을 L-공간에서 암묵 흡수하는 필터였다 —
Θ/ω 불일치는 그 흡수의 대가. 부산물 발견: τ = bias − JᵀW 는 접촉력 = W 를
정확히 실현하므로, 상체 모델을 쓰면 다리 무게 '전부'가 wrench 에 매달린다
(유효 중력 g·M_tot/M_ub). 코드는 절단 장비로 보존: src/11_walk_srb_upper.py.

## 3. 근사 ② 회전 동역학 선형화

원래 회전은 세 군데가 비선형인데 전부 잘라냈다:

| 원래 | 우리 | 버린 것 |
|---|---|---|
| `d(Iω)/dt = I ω̇ + ω×(Iω)` | `I ω̇` | **자이로스코프 항** ω×(Iω) |
| `I_world = R I_b Rᵀ` | `Rz(ψ) I_b Rz(ψ)ᵀ` | roll·pitch 에 의한 관성 변화 |
| `Θ̇ = T(Θ)⁻¹ ω` (전체 오일러 변환) | `Θ̇ = Rz(ψ)ᵀ ω` | roll·pitch 작은 각 가정 |

**타당성**: 보행 중 ω < 0.5 rad/s 라 ω×(Iω) < 1 N·m (발목 권한 8~20 N·m 대비 무시 가능).
roll/pitch 도 ±8° 내. **지금 병목 아님.** 단 넘어지는 중(pitch 30°+)에는 깨지는데,
그땐 이미 다른 게 다 깨진 뒤라 무의미.

**Di Carlo 트릭**: 중력이 아핀 항(상수)이라 선형계가 안 되는 문제를 **중력상수 9.81을
13번째 상태로 넣어** 해결. `ġ=0`, `v̇_z ← −g`. 순수하게 형식을 위한 꼼수.

## 4. 근사 ③ 상태 정의 — 여기에 구조적 결손이 있다 ★

상태 13개를 어디서 재는가는 "정의"의 문제인데, **일관성이 깨져 있다**:

| 상태 | 어디서 읽나 | 무엇을 대표하나 |
|---|---|---|
| p, v (CoM) | `subtree_com`, `subtree_linvel` | **전신** |
| ω | `I⁻¹ · subtree_angmom` | **전신** (각운동량) |
| **Θ (자세)** | **pelvis 쿼터니언** | **골반 하나** |

**결과**: 다리를 앞으로 던지면 → 골반이 뒤로 돎 → `Θ = 21° 기울음`, 그런데 각운동량은
내부 상쇄 → `ω ≈ 0`. 즉 **"기울었는데 안 돈다"** — 강체라면 불가능한 상태.
모델의 운동학 식 `Θ̇ = Rz(ψ)ᵀω` 가 **걷는 동안 상시 위반**된다.

- 왜 Θ만 골반인가: 전신의 "자세"라는 개념이 다물체에는 없다. 각운동량은 합이 정의되지만
  각도는 합이 정의 안 됨. (centroidal frame 을 쓰는 방법은 있지만 미구현)
- 왜 ω는 전신인가: 골반 ω를 쓰면 서스펜션 내부 진동을 몸 전체 회전으로 오인해
  MPC가 유령과 싸우다 발산했다 (외란 실험에서 292 N·m 가 필요한 회전을 14 N·m 로
  관측 → 물리적 불가능 → 측정 오류 확정).
- 현재 대응: **상체 17관절 PD로 골반≈전신이 되도록 로봇을 강제** = 밴드에이드.
  관측 모델을 고친 게 아니다.

**아이디어 후보 지점**: centroidal 자세 정의, 상체-다리 상대자세를 상태에 추가,
또는 이 gap 을 residual RL 에 맡기기.

## 5. 근사 ④ 접촉 — 상보성을 스케줄로 대체

### 원래
접촉은 **하이브리드**: 닿으면 힘이 생기고 떨어지면 0. 언제 닿을지는 상태에 달림
(상보성 조건). 이대로면 MIP(정수 최적화)라 실시간 불가.

### 우리
**고정 타이밍 스케줄**로 언제 어느 발이 땅에 있는지를 **미리 정해버린다**:
- 주기 T=0.8 s, stance 75% (swing 0.2 s), 좌우 위상 0.5 차 → double support 자연 발생
- swing 발: 해당 wrench 6개 = 0 **등식 제약** + B 열 0
- 이러면 문제가 QP 로 유지됨 (Di Carlo 방식)

### 대가
1. **일찍/늦게 닿는 것을 처리 못 함.** 스케줄이 "stance"라는데 발이 공중이면 MPC 는
   있지도 않은 지면을 밀라고 명령한다 → 낙하 → 킥. (임피던스 kp=350→2500 으로
   추종을 빳빳하게 해서 회피 중 = 증상 억제)
2. 충격 흡수 계획 없음 — 착지 순간 수직속도 ~0.8 m/s 가 그대로 충격.
3. stage-0 정합: 접촉표는 구간 중점 기준인데 토크 계산은 현재 기준 → 25 ms 어긋남을
   발견해 수정함 (`contact[0] = in_stance(t)`).

**미구현**: 착지 타이밍 적응(early/late touchdown), 접촉 전환 블렌딩.

## 7. 근사 ⑦ wrench → 관절토크 (실현 계층) ★ 두 번째 큰 간극

MPC 는 "발에 이 wrench 를 주라"까지만 말한다. 관절 토크로 바꾸는 건 우리 몫:

```
τ = qfrc_bias                    ① 중력·코리올리 (MuJoCo 전체 모델 — SRB 가 버린 다리 중력을 여기서 회수)
  − Σ_stance J_iᵀ W_i            ② wrench → 토크 (가상일 원리)
  + Σ_swing Jᵀ(Kp e + Kd ė)      ③ swing 임피던스 (kp=2500, 힘 상한 200 N)
  + M(q) q̈_swing,des             ④ WBC-lite (2라운드에서 추가)
  + 상체 17관절 PD                ⑤ 밴드에이드 (§4)
```

### ②의 숨은 가정 — 여기가 샜다
`τ = qfrc_bias − JᵀW` 는 전체 운동방정식 `M q̈ + h = Sᵀτ + Jᵀf` 에서 **`M q̈ = 0`
(준정적)** 을 가정한 것. swing 다리가 50 m/s² 로 가속하는 순간 이 가정이 깨지고,
**M 이 밀집이라 swing 관절의 q̈ 이 stance 관절 행에 결합** → 명령한 wrench 와 실제
지면반력이 달라진다. (로그 증거: Fx 명령 +50 N 인데 vx 는 하락)

### ④가 막는 방법
swing 궤적은 우리가 계획한 것이므로 `q̈_swing,des` 를 해석적으로 안다
(smoothstep 2계도함수 → 전반 +, 후반 − 의 **양극성** 자동). 이걸 `M(q)` 에 곱하면
밀집 구조가 **stance·base 관절 몫의 보상까지 자동 배분**.
- 효과: 0.25/0.3 m/s 완주 (baseline 6.5/6.4 s 전도)
- **근사 남음**: `J̇q̇` 항 생략, `q̈` 는 계획값(실제 추종 오차 무시), ‖q̈‖≤300 클램프,
  swing 다리 6 dof 자코비안 역만 사용(전신 IK 아님)

### ③의 임시방편
- kp=2500 (≈3.5 Hz) — 무르면 착지 지각, 세면 반작용 증가. 힘 상한 200 N 은
  **물리 근거 없는 임의값** (400 으로 올리는 실험은 무효였음)
- 발 자세는 "z축을 world z 로" 스프링 — toe-out/경사면 미대응

## 8. MPC 바깥의 휴리스틱 (모델에 없는 것들)

이것들은 **물리에서 유도된 게 아니라 넣어준 규칙**이다. 튜닝 여지와 개선 후보가 몰려 있음.

| 항목 | 현재 | 근거 | 미해결 |
|---|---|---|---|
| **착지점** | `hip + v_cmd·T_st/2 + (v−v_cmd)/ω₀ + 0.15(CoM−ref)` | LIP capture point (ω₀=3.92, 1/ω₀=0.255) + 위치 피드백 | 최적 게인은 T_st 의존(H-LIP). 1/ω₀ 는 "순간" 값이라 주기 보행 최적치와 다름 |
| **sway 참조** | 지지중심의 β=0.5 만큼, 속도제한 0.4 m/s 램프 | 없음 (경험) | 사다리꼴이라 꺾임점에서 급가속 명령 |
| **swing 궤적** | xy smoothstep + z 사인 아치 (h=5 cm) | 없음 | **착지 수직속도 ≈0.8 m/s 잔존** (5차 Bezier 로 0 만들 수 있음) |
| **gait** | T=0.8, stance 75%, 고정 | 없음 | **속도별 스윕 미실시** |
| 스텝 제한 | max_step 0.30, min_y_sep 0.06 | 기구학 추정 | 실제 도달영역 미검증 |
| 교차 방지 | body y 부호 유지 | 휴리스틱 | — |
| **팔** | 제자리 PD | — | **21% 질량이 놀고 있음** |

## 9. 가중치 (= 대역폭 설계)

```
Q = [10,10,20 | 50,50,300 | 5,5,5 | 20,20,50 | 0]   # Θ | p | ω | v | g
R = 1e-5 균일, u_ref = 중력 ff (발당 Mg/2)
```
- Q/R 비 → LQR 근사 `ω_n=(q/r)^¼/√I` → 자세루프 ~3 Hz. 지연(MPC 10 ms + 실현)
  ~25 ms 에서 위상여유 확보. Q_Θ=300(≈8 Hz)은 발산했다.
- 4제곱근이라 **가중치 10배 = 대역폭 1.8배**. 로그 스케일로 움직일 것.
- **비대칭 없음** — OA-MPC 는 roll:pitch=10:1, vy:vx=10:1, 채널별 decay 를 쓴다.
  우리는 전부 균등. (그들 값은 TSC 2층 구조 전제라 직접 이식 불가, 철학만 참고)

## 12. 흔들림 3분류 (개선 논의용)

"몸통이 흔들린다"는 **세 개의 다른 현상**이고 처방이 다르다:

| 종류 | 크기 | 원인 | 필연성 |
|---|---|---|---|
| **횡 sway** | CoM y ±3.7 cm, 1.25 Hz | **우리가 의도**(β_sway) — 한 발 지지 때 CoP 위로 체중 이동 | **필수** (없애면 넘어짐). 매끄럽게만 |
| **roll/pitch 요동** | ±5~8°, swing 마다 | swing 반작용 (§2) + Θ/ω 불일치 (§4) | 불가피하나 **상쇄 가능** (팔 스윙) |
| **고주파 떨림** | ω 스파이크 0.4 rad/s | 착지 충격(§8-9) + 전환 불연속(§8-10) | **없앨 수 있음** |
