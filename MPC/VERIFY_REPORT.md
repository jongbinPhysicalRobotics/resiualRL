## 1. ★ 오류: 제약 행렬이 site↔접촉점 3 cm 오프셋을 빠뜨렸다

접촉 구는 발 site 보다 local z=−0.03(+반지름) 아래. wrench 를 site 에서 정의했으므로
수평력 Fx/Fy 가 이 팔길이로 발목 모멘트를 추가로 만든다. 지면 접촉점 P 의 wrench 를
발목 A 로 옮기면 m_A,y = m_P,y − h·Fx, m_A,x = m_P,x + h·Fy. CoP 조건은 지면 wrench
에 대한 것이므로 정확한 제약은:

```
−l_t·Fz ≤ my + h·Fx ≤ l_h·Fz,     −w·Fz ≤ mx − h·Fy ≤ w·Fz
```

- 서 있기(Fx≈0)에선 결합항이 0 → Step 1 은 이 항을 검증할 수 없는 테스트였다.
- 크기: |Fx|≤μFz 에서 오차 최대 0.018~0.021·Fz — 피치 뒤꿈치 마진의 ~40%,
  **롤 마진의 ~70~84%**.
- 전진 중 Fx>0 일 때 MPC 가 뒤꿈치 권한을 과대평가 → 후방 전도 양상과 직결.
- 수정은 선형 — 행렬 4개 원소만 바뀜. h 는 모델에서 추출할 것 (하드코딩 금지).
- 잠복: 제약이 world frame 인데 발 frame 가정 (yaw≠0 시 틀어짐) → blkdiag(Rzᵀ,Rzᵀ) 삽입.

## 2. B 행렬 — 정상. 단 노트 오기·잠재 버그

- B 블록·Rz(ψ)ᵀ·자동미분 대조 모두 정상.
- Step 3 "자동미분 대조 ✓"는 물리 검증이 아니다 — 전사(transcription) 오류가 없다는
  뜻일 뿐. f 자체의 부호가 틀렸으면 둘 다 똑같이 틀린다. B 의 물리 검증은 유도 + 서
  있기 성공이 하는 것.
- 노트 오기: "roll 은 I_xx=0.54" → 0.542 는 I_zz(yaw). I_xx=3.55. 롤 취약 원인은
  관성이 아니라 반폭 2.5 cm 의 발목 권한(~8 N·m).
- 잠재: make_params 의 world 관성 ↔ continuous_AB 의 Rz(ψ) 이중 회전 (yaw₀≠0 시).
  k=0 선형화점은 현재 상태로. Euler 는 A 멱영이라 정확한 ZOH 가 닫힌 형태.

## 3. Capture point & k_pos — 부호 논리 정상

- +k_pos 부호는 LIP 로 정당: ÿ = ω₀²(y − p_foot). 밀린 쪽으로 더 딛어야 복원.
  이전 anchor(반대 부호)가 위치 불안정이었다는 진단도 정확.
- "1/ω₀ = 정답"이라 쓰면 심사에서 걸림 — 순간 capture point 게인이 이 주기에서
  경험적으로 최선이었다 정도가 정확 (S2S 최적 게인은 T_st 에 의존, H-LIP 계열).
- LIP 높이는 CoM − 지면으로.
- 횡 위치를 MPC(Q_py·sway 참조)와 발디딤(k_pos) 두 루프가 동시에 제어 중 — 튜닝 시
  둘을 동시에 움직이지 말 것.
- 관찰: side_offset 을 초기 (foot−CoM) 으로 잡아 공칭 CoP 가 발 중심보다 2.2 cm 뒤 —
  후방 마진을 스스로 깎고 있음. side_offset_x +2 cm 검토.

## 4. "각운동량 기반 ω는 내부 회전을 못 본다" — 역학적으로 맞음, 진단은 한 층 더

- L 재분배 논리 정상, ω=I⁻¹L 이 SRB 와 일관된 선택인 것도 정상.
- 빠진 진단: Θ는 pelvis 자세, ω는 전신 평균 각속도 → **상태 안에서 Θ̇ = Rzᵀω 가
  내부 운동이 있는 동안 항상 위반**된다. "Θ 피드백만 남음"이 이 불일치의 증상.
  상체 PD 는 몸통을 pelvis≈전신으로 만드는 밴드에이드. "ω가 못 본다"보다
  **"Θ와 ω가 같은 강체가 아니다"**로 적어야 한다.
- 정밀도: L 은 정확히 보존되지 않음 — stance 발목 모멘트가 외부 토크 (0.2 s 에
  ΔL 최대 ~4 N·m·s).

## 5. "0.2 m/s 벽 = swing 반작용 = massless-leg" — 빈틈 있음

숫자·방향(200 N/28 kg ≈ 7 m/s², 후방 전도)은 맞다. 그러나 단정하려면 배제 필요:

- (a) 200 N 상한 → 늦은 착지 (반작용과 구분 불가). 0.3 필요힘 ~260 > 상한 200.
- (b) "SRB 는 반작용을 원천적으로 모른다"는 과장 — swing 임피던스 힘은 네가 계산하는
  값. known disturbance 로 넣을 수 있음. residual RL 의 gap 이라 주장하려면 이 모델
  기반 처방을 먼저 해보고 남는 것을 gap 이라 불러야 정직.
- (c) "−5 m/s² 제동"은 지속이 아니라 과도 — 한 swing 순 임펄스 ≈ 0 (전반 후퇴,
  후반 전진). 대책은 상수가 아니라 양극성(가속→감속) 패턴.
- (d) stage-0 접촉 판정: contact_table 중점 t+25 ms vs torque() 현재 — 착지 25 ms
  전부터 허공에 W>0. contact[0] = in_stance(t) 로 수정.
- (e) gait 타이밍 고정 (T=0.8, swing 0.2) — 속도별 스윕 없이 "속도 한계"라 하면
  "그건 그 gait 의 한계"라는 반박이 나옴.
- (f) Θ/ω 불일치는 걷는 동안 상시 작동 — 피치 예측 오차가 속도와 함께 커짐.

격리 실험 (저비용, 우선순위): ① 다리 질량 1/3 → 0.3 재실행 (가장 결정적)
② 상한 해제 + 착지 시각 확인 ③ 임피던스 반작용 vs SRB 예측 나란히 로깅.

**논문 직결**: swing 반작용 feedforward 는 우회책이 아니라 **필수 baseline** —
없으면 심사 첫 질문이 "그거 feedforward 한 줄이면 되는 거 아니냐"가 된다.
