## Q1. 속도 벽 (9/25 Q10) 후속 — 착지 미리보기 k_half 전환이 원인인가

**결론**: **절반만 맞다** (측정). k_half 전환 (명령 0.60 초과에서 0.37 → 0.28/0.26, 미리보기 10 % 축소) 은
0.625+ 에서 "명령보다 **과속**하다 넘어지는" 모양을 만들고, 고정하면 그 모양이 사라지고 생존도 3 ~ 4 배 길어진다.
**그러나 0.6 m/s 벽 자체는 그대로다** — 0.625 부터 결국 모두 넘어진다.

### 1. 배경 (글 8.1 절, 코드 사실)

착지점의 전진 몫 = 명령 속도 × Tp, Tp = (0.5 + k_half)·0.33 s. k_half 는 명령 속도로 전환:
0.60 이하 0.37 (Tp 0.287 s) / 0.60 초과 0.28 (0.257) / 0.65 초과 0.26 (0.251) — strict `>` 라 0.600 은 0.37
([planner.py](../MPC/src/mit/planner.py) `selected_half_stance_offset`). 즉 0.600 → 0.625 로 명령을 올리면
착지 미리보기 거리가 0.172 → 0.161 m 로 **줄어든다**. 우리 벽 (0.600 ✓ / 0.625 ✗, 9/25 Q10) 과 전환 속도가 정확히 겹친다.

### 2. 시험 — `khalf` 변형 키 ([10_walk.py](../MPC/src/mit/10_walk.py), 기본 = 기존 전환)

`khalf=0.37` = 속도와 무관하게 Tp 0.287 s 고정. 120 s, 램프 + yawref, xmax=1.0.

| 명령 vx | 기존 전환 (Q10) | khalf=0.37 (이식 OSQP) | khalf=0.37 (reference 실효 OSQP) |
|---|---|---|---|
| 0.6 | ✓ 88 % | ✓ 88 % (동일) | ✓ 84 % |
| 0.625 | ✗ 6.6 s, 추종 119 % (과속) | ✗ 10.2 s, 104 % | ✗ 10.5 s, 68 % |
| 0.65 | ✗ 7.1 s | ✗ 14.2 s, 90 % | ✗ 23.7 s, 73 % |
| 0.7 | ✗ 5.6 s, 143 % (과속) | ✗ 21.3 s, **72 % (저속)** | ✗ 17.8 s, 62 % |
| 0.8 / 0.9 / 1.0 | ✗ 5.1 / 4.6 / 4.1 s | ✗ 5.1 / 4.0 / 3.5 s | ✗ 4.9 / 4.2 / 3.8 s |

### 3. 읽기

- 전환이 있으면 발을 덜 앞에 디뎌 **과속** (0.7 명령에 실제 0.89 ~ 1.0), 고정하면 발이 많이 앞에 놓여
  브레이크가 걸려 **저속** (0.7 명령에 0.43 ~ 0.50). 두 OSQP 설정에서 같은 방향 — 우연 아님.
- 벽의 나머지 원인은 미확인 — 걸음 시간표 (주기 0.5·스윙 0.17 s), 주기 원점 접촉표 (O1), 모델 차이 후보 (추론).
  저자도 "0.7 m/s 명령 상한, 보수적 걸음" 이라 적음 (문헌).
- 관련 확인 (글 8.3 + 측정): 매 걸음 early contact (~20 ms 조기 착지) 는 버그가 아니라 **착지 목표 z = −5 mm 설계**
  — 55 mm 정점에서 내려오는 smoothstep 이 스윙 91 % 지점에서 z=0 을 지난다 (유도 ≈ 15 ms, 측정 17 ~ 22 ms).

## Q2. CasADi 재작업 1 단계 — condensed QP 를 기호식 + 자동미분으로 재구현, 이식과 기계 정밀도 일치

**결론**: [mpc_casadi.py](../MPC/src/mit/mpc_casadi.py) 의 `CasadiCondensedMPC` 가 이식 (mpc.py) 과
**행렬은 1e-11 이하, 폐루프는 같은 성적 (0.6 에서 120 s · 84.5 %)** 으로 일치한다 (측정).
동역학을 f(x,u) 로 한 번 적고 A_c·B_c 를 **자동미분**으로 뽑는 구조 — 이제 항을 추가할 때 손 유도 실수가 사라진다.
OA-MPC 선 접촉 제약 (`foot_model="line"`) 도 플래그로 구현 — **첫 A/B 는 개선 없음** (아래).

### 1. 구조

| 부분 | 구현 |
|---|---|
| 동역학 → A_c, B_c | CasADi 기호식 + `ca.jacobian` (손 채움 대체) — u 순서 [F_L, F_R, M_L, M_R] 주의 |
| ZOH 이산화 · Q_k 비용 회전 · 발 yaw 제약 회전 | CasADi 기호식 (reference 식 그대로) |
| condensing (lift) · H/q 곱 · sparsity 패턴 · OSQP 층 (warm start·cold·fallback) | 기존 ConvexMPC 상속 (9/25 Q11 에서 C++ 과 0 ~ 9e-17 로 검증된 구조부) |

### 2. 검증 ([15_casadi_check.py](../MPC/src/mit/15_casadi_check.py) `shadow`, 0.6 램프 + yawref, 11 s, 풀이 786 회)

| 항목 | 최대 \|차이\| |
|---|---|
| A_d / A_qp | **0** |
| B_d / B_qp | 6.9e-17 / 9.0e-17 |
| H / q | 9.1e-12 / 1.1e-11 (H 상대 2.1e-15) |
| 제약 blk · 경계 | 0 |
| u0 (독립 OSQP workspace 둘) | 1.3e-7 N |

처음엔 B_d 가 0.119 달랐는데 **내 입력 순서 실수** ([F_L, M_L, F_R, M_R] 로 적음) — 자동미분·손 채움의 차이가 아니었다.
조립 시간 CasADi 2.7 vs 이식 2.1 ms/solve. 폐루프 (`closed --foot ref --refosqp`): 120 s · 추종 84.5 %,
fallback 0, cold 0.111 — 이식의 84 % (9/25 Q11) 재현.

### 3. ref 발 모델이 요청하는 불가능한 roll 모멘트 (측정)

걷는 동안 이식 (foot_half_width 0.01) 의 u0 디딤 발 |mx^F| = **평균 1.35 · p95 3.06 · 최대 4.6 N·m**.
발은 선 접촉 (9/26 논의: 접촉점 2 개, y = 0) 이라 지면이 이 모멘트를 못 준다 — 다리 토크로는 나가고 반작용이 없어
그만큼 몸 roll 외란이 된다 (추론). line 모델이 이걸 0 으로 만든다.

### 4. OA-MPC 선 접촉 (`foot_model="line"`, Ding et al. Humanoids 2022 §III-F) — 첫 A/B (n = 1 씩)

mx^F = 0 등식 (D 행, no_roll_moment 자리) + CoP ±0.065·Fz + 비틀림 4 행 (발끝·뒤꿈치 두 점 마찰 유도:
|mz + a·Fy| ≤ µ(a·Fz − my), |a·Fy − mz| ≤ µ(a·Fz + my)) 이 폭 ±0.01 CoP · 0.0657µFz 비틀림을 대체.

| 명령 vx | ref 발 (기준) | line 발 |
|---|---|---|
| 0.6 | ✓ 120 s · 84 % | **✗ 33.4 s** · 78 % |
| 0.625 | ✗ 6.7 s | ✗ **36.3 s** · 88 % |
| 0.65 | ✗ 7.0 s | ✗ 6.9 s |
| 0.7 | ✗ 5.8 s | ✗ 6.9 s |

**물리적으로 맞는 제약이 자동으로 더 잘 걷게 하지는 않는다** — 0.6 은 후퇴, 0.625 는 5 배 연장, 0.65+ 불변.
생존 시간이 혼돈에 민감한 건 9/25 Q11 앙상블 (같은 설정에서 7.8 ~ 36 s) 에서 본 그대로라, n = 1 로는 판정 보류.
가설 (미검증): mx = 0 이 남는 세 모멘트의 마찰 예산을 조이고 (mz 가 Fy·my 와 결합), yaw 되먹임 (yawref) 이 쓰는
mz 권한이 줄었을 수 있다. 다음: 앙상블로 재기 + tuning (Q/R) 을 line 전제로 다시 보기.

### 5. 남은 것 (계획 2 단계 나머지)

sparse (multiple-shooting) 형태 — 상태·입력을 모두 변수로 두고 동역학을 등식으로. Residual MPC 와 같은 구조라
다음 단계의 발판. condensed 와 같은 해가 나오는지 + OSQP 반복 수·시간 비교가 검증 항목.

### mit 폴더와의 차이 (전부 이 폴더 기본값 이야기 — mit 는 기록 보존용으로 동결)

4. `GAIT_ON` (gait.py 파일 값 1, 환경변수 우선): 0 이면 FSM standing 으로 제자리 서기 — G1 폴더 관례.
5. `--foot line` (OA-MPC 선 접촉) 은 플래그로만 — 기본 ref. mx = 0 잡는 건 나중에 튜닝과 같이 (사용자 결정).
