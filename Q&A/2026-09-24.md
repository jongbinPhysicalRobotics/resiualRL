### 판정

- **아핀항: 세 속도 모두 120 s 완주.** 40 s 수치가 그대로 유지된다 (0.5: 2.63 → 2.64°, 0.7: 3.10 → 3.10°) — 오래 걸어도 쌓이는 문제가 없다.
  기준 대비 pitch 흔들림 **−25 / −21 / −23 %**, 골반 yaw −41 / −28 / −26 %, 착지 후 발가락 하중 0 구간 5→0 / 26→19 / 43→28 ms.
  추종·하중 인계(합력최저)·스윙 토크는 그대로. 나빠진 것은 0.5 발 yaw 미끄럼 0.2 → 0.7° 와 디딤 무릎 방향 (+0.5 → +1.4°, 0.7 에서 +2.2 → +3.6°) 정도 — 둘 다 RL 범위 (≤ 2.6°) 안이지만 0.7 무릎은 경계.
- **분리: 0.5 · 0.7 에서 전도 (27 s, 62 s).** 0.3 은 완주하지만 추종 85 %, 스윙 토크 초과 89 %. 지금 형태로는 후보가 아니다 — MPC 쪽 패키지 (`--refq --refhorizon`) 를 옮기기 전까지 보류.

## Q2. 분리에 reference MPC 가중치를 세게 넣으면?

> Q1 에서 분리가 0.5 · 0.7 전도. reference 는 센 스윙과 **센 MPC 위치 가중치**를 한 묶음으로 쓰므로 그 절반을 마저 옮겨 본다.
> `refq` = reference G1 walking 가중치 (자세 900, 위치 3000/42000/50000, R 1e-7 — 우리 10~20 / 50~300 / 1e-5),
> `refh` = reference 지평 (N 25 × dt 0.02 = 0.5 s — 우리 16 × 0.05 = 0.8 s). 120 s.

**읽기**
- **가중치가 앞기울기는 잡았다** (+7 ~ 11° → +1 ~ 2°), roll 흔들림도 절반. 0.5 가 120 s 완주로 바뀌었다.
- 대신 **걷지를 못한다** — 추종 58 % (0.5), 28 % (0.7). 위치 가중치가 워낙 커서 MPC 가 몸을 제자리 참조에 붙잡는 데 힘을 다 쓴다.
- **하중 인계가 무너졌다** — 착지 후 합력 최저 체중의 10 ~ 15 % (기준 53 ~ 57 %). R 1e-7 에서 힘 분배가 한 발에서 다른 발로 튄다 (9/21 Q8 의 R 문제가 100 배 커진 것).
  그 결과 발 yaw 미끄럼 8°, 디딤 무릎 안쪽 +5 ~ 7° — 9/22 에 잡은 "발이 돌고 무릎이 꺾이는 사슬" 이 다시 나왔다.
- **스윙 토크 초과 88 % 는 그대로** — MPC 와 무관하게 reference 발자세 PD 쪽이다 (9/23 Q11).
- **refh 는 1.8 s 전도.** 분리 문제가 아니다: 기준 09_walk 에 지평만 0.5 s 로 바꿔도 제자리에서 3.7 s 전도.
  우리 걸음 주기는 0.8 s (스윙 0.34 s) 라 0.5 s 지평이 한 주기를 못 덮는다 (09_walk 주석: 0.64 s 도 0.8 s 보다 나빴다).
  reference 는 주기 0.7 s 에 맞춘 값이고, N 25 는 QP 도 13 ~ 34 ms 로 100 Hz 예산(10 ms)을 넘는다.

**판정: 분리는 가중치를 옮겨도 후보가 안 된다.** 기울기를 고치는 대신 속도·하중 인계를 잃었다.
reference 는 이 가중치에 ContactManager (하중 램프), 짧은 주기, 발목 한계를 견디는 설정이 같이 있어야 성립하는 **한 묶음**이고,
하나씩 옮길 때마다 다른 곳이 깨진다 (9/15 상체 SRB 실험과 같은 결론). **아핀항 쪽으로 간다.**
