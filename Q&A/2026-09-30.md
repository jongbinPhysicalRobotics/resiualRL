## Q1. A10 의 slip 은 무엇이고 어떻게 줄이나 — 앞꿈치 축 회전, 선 접촉 제약은 효과 없음, 팔 흔들기 1.0 으로 절반 (A11)

사용자 관찰 (A10 렌더): 앞발 (앞꿈치) 을 축으로 뒤꿈치가 도는 현상이 보인다. slip 이 이것인가, 두 발 접촉은 거의 없는가.

### 1. slip 지표의 정체 (코드 사실 + 측정)

- `slip_mm` = 착지 10 ms 뒤부터 이륙까지 **발 중심점 (contact site) 의 수평 이동** 평균 ([10_walk.py](../MPC/src/casadi_mit/10_walk.py) `compute_metrics`).
- 발 중심은 앞꿈치에서 75 mm 떨어져 있다 → 앞꿈치를 축으로 θ 돌면 75·tan θ 만큼 slip 으로 잡힌다.

| | 뒤꿈치 회전 (입각 동안) | 75 mm × tan θ | 측정 slip |
|---|---|---|---|
| A8, 0.8 m/s | 5.2 ~ 5.5° | 약 7 mm | 7.9 mm |
| A10, 0.8 m/s | 7.7 ~ 9.4° | 약 10 ~ 12 mm | 14.8 mm |

→ slip 의 대부분은 앞꿈치 축 회전이다.

두 점 접촉 비율 (13_foot_diag, 20 s, 입각 시간 중, 측정):

| | 두 점 | 앞꿈치만 | 뒤꿈치만 |
|---|---|---|---|
| A8, 0.6 | 약 48 % | 43 % | 10 % |
| A10, 0.6 | 약 42 % | 45 ~ 46 % | 12 ~ 13 % |
| A8, 0.8 | 약 46 ~ 49 % | 42 ~ 43 % | 9 ~ 12 % |
| A10, 0.8 | 약 33 ~ 34 % | 51 ~ 52 % | 15 % |

### 2. 언제 도는가 (A10, 0.8, 입각 구간별 평균, 측정)

| 입각 % | 뒤꿈치 Fz | 앞꿈치 Fz | MPC Mz | 누적 회전 |
|---|---|---|---|---|
| 0 ~ 40 | 207 → 37 N | 113 → 139 N | +2 ~ −4 N·m | −0.3 ~ −2.2° |
| 40 ~ 60 | 15 ~ 18 N | 112 ~ 136 N | −8.8 ~ −5.9 N·m | +2.8 → +6.4° |
| 60 ~ 100 | 0 ~ 99 N | 61 ~ 209 N | −6.5 ~ −0.7 N·m | +7.7 ~ +8.0° |

- 입각 중반, 앞꿈치 한 점으로 설 때 MPC 가 yaw 모멘트 6 ~ 9 N·m 를 명령하고 그때 돈다 (순서 = 측정, 인과 = 추론).
- reference 발 제약의 비틀림 한계 |Mz| ≤ 0.0657µFz 는 CoP 와 무관하다 (코드 사실) → 한 점 접촉에서도 비틀림을 허용한다 (9/28 Q1 과 같은 기전).

### 3. 선 접촉 제약 (`foot=line`, OA-MPC — 비틀림을 CoP 에 묶음) 시험 (A10 기준, 60 s, 측정)

| 변형 | 0.6 slip | 0.8 | 0.6+0.5 | 회전 1.3 / 1.5 slip | 옆 외란 20 · 30 N |
|---|---|---|---|---|---|
| A10 | ✓ 8.7 | ✓ 14.8 | ✓ 8.1 | 3.3 / 4.1 | 16/16 |
| line + CoP 0.05 | ✓ 8.2 | ✓ 13.5 | ✓ 8.8 (vy +0.054) | 5.2 / 10.7 | 16/16 |
| line + CoP 0.05 + yaw hold 끔 | ✓ **23.9** | ✗ 5.2 s | ✗ 18.4 s | 1.7 / 1.8 | 13/16 |
| line + yaw hold 끔 | ✓ **24.5** | ✗ 16.7 s | ✓ 29.0 | 1.7 / 1.9 | — |

- line 만으로는 거의 줄지 않는다.
- 디딤 발 yaw hold (MPC 밖에서 Mz 추가, m = 20·오차 − 4·각속도) 를 끄면 회전 · 옆걸음 slip 은 사라진다. 대신 **곧은 걸음 slip 이 24 mm 로 폭증**하고 0.8 에서 넘어진다.
  → 곧은 걸음에서 발이 도는 것을 지금 막고 있는 것은 yaw hold 다.
- 해석 (추론): 곧은 걸음에서도 yaw 모멘트가 많이 필요하다.
  스윙 다리를 휘두르는 반동이 몸통을 매 걸음 ±0.25 rad/s 로 흔든다 (9/29 Q8 측정). 이를 딛는 발 비틀림으로 막다가, 앞꿈치 한 점으로 설 때 발이 돈다.
  → 제약을 바꾸기보다 **반동 자체를 줄여야** 한다.

## Q3. 보행 주기 다시 설계 — 예측 구간은 늘리면 안 된다 (0.44 s 고정), 긴 주기도 천장 (약 0.88 m/s) 은 못 넘는다

### 1. 무엇을 넣었나 (새 키 `swlim`, 기본 0 = 지금 방식 — 관절별 자르기)

## Q5. 1 m/s 를 연 것은 스윙 PD 게인 — 착지 직전 hip 토크의 대부분이 되먹임 (발 오버슈트 × 딱딱한 PD). ω 0.46 배 + 감쇠비 0.7 로 실측 0.96 m/s (A12)

### 1. 스윙 궤적의 끝 속도 (코드 사실)

- `SwingFootTrajectory` = 3 차 smoothstep b(s) = 3s² − 2s³ (코드 주석 "Bézier 아님").
  - b'(0) = b'(1) = 0 → 이륙 · 착지 수평 속도 0.
  - b''(0) = +6, b''(1) = −6 → 가속은 양 끝에서 최대 (6·d/T²).
- 수직은 두 반쪽 (이륙 → 최고점 → 착지) 모두 같은 곡선 → 이륙 · 최고점 · 착지 수직 속도 0.
- 끝 속도 v0, v1 이 있으면 양 끝 가속은 (6d − 4v0T − 2v1T)/T², (−6d + 2v0T + 4v1T)/T² (유도).
  수평 착지 속도를 앞으로 남기면 감속은 줄지만 발이 미끄러지며 닿는다.
- 논문은 수직 (z) 높이 곡선에만 이륙 · 착지 속도를 둔다 (5 차 베지어, 식 (11) ~ (15)).

## Q11. 발표에 "선 접촉 (OA-MPC line foot)" 이라고 쓰려면 — A16 은 Mx ≠ 0 인 reference 발이었다. full line 으로 다시 세움 (A17)

사용자: "발표에는 OA-MPC 의 line foot contact 를 썼다고 할 건데 Mx 가 0 이 아니면 문제" → "line foot contact 로 제약 확실하게 걸고 다시".

### 1. 문제와 사실

- **A16 의 발 제약은 reference 그대로 (`foot=ref`)** 였다 (코드 사실, [mpc.py](../MPC/src/casadi_mit/mpc.py) `foot_constraint_template`):
  |Mx| ≤ b·Fz (b = 발 반폭 0.01 m) → **Mx ≠ 0 허용**, CoP 앞뒤 |My| ≤ 0.065·Fz, 비틀림 |Mz| ≤ 0.0657µFz (CoP 와 무관한 상수).
- **시뮬 발은 두 점 접촉이다 (측정)**: 서 있을 때 MuJoCo 접촉점이 발마다 2 개, 발 site 기준 x = **±0.075 m** (원기둥 반길이), y · z ≈ 0.
  바닥 condim 3 → 점마다 비틀림 마찰 없음, 마찰 사각뿔 (코드 사실, scene.xml).
  즉 **실제 접촉은 논문의 발끝 · 뒤꿈치 두 점 모델** 그대로다.
- 논문 (Residual MPC, 3473 쪽): 한 발에 발끝 · 뒤꿈치 두 점, 점마다 3 차원 힘 (n_c = 4, F ∈ ℝ¹²), 점마다 ‖F_xy‖ ≤ µF_z.
  부록 B 의 m_x = g(f_x, f_y, f_z, m_y, m_z) 는 관절 토크 → wrench 로 되돌리는 **분석용** 식이다 (MPC 제약 아님).
- 두 점 힘을 발 중심 wrench 로 바꾸면 (유도, 발끝 +l · 뒤꿈치 −l):
  Mx = 0 (두 점이 선 위), My = l(fz_뒤 − fz_앞), Mz = l(fy_앞 − fy_뒤). 점마다 fz ≥ 0 → |My| ≤ l·Fz,
  점마다 y 마찰 → **|Mz + l·Fy| ≤ µ(l·Fz − My), |l·Fy − Mz| ≤ µ(l·Fz + My)** — 이것이 `foot=line` (OA-MPC) 의 비틀림 행이다 ([mpc_casadi.py](../MPC/src/casadi_mit/mpc_casadi.py) `line_foot_template`).
  → **CoP 가 발 끝에 붙으면 비틀림은 옆 힘으로만 만들 수 있다: Mz = ±l·Fy** (유도).
