## 3. 스윙 임피던스 — 고정 게인에서 Λ 스케줄로

**시작**: 상수 `kp=2500`. 자세에 따라 발끝 겉보기 관성이 달라지는데 게인이 고정이라
**수직 등가 대역폭이 15.6 rad/s 뿐** → 추종률 48 %

**발전** (9/15, 23절):

- `Λ = (J M⁻¹ Jᵀ)⁻¹` (작업공간 겉보기 관성) 을 매 스텝 계산해
  `kp = ω_n²·diag(Λ)`, `kd = 2ζ·ω_n·Λ` — **자세가 변해도 대역폭이 ω_n 으로 일정**
- 1차 시도 `ω_n=100`, `kd` 고정 → ζ≈0.04 저감쇠로 **5 cm 명령을 22 cm 오버슛**, 11 s 전도
- `kd` 도 Λ 스케줄 → ζ=0.5 도 실패(반작용 증폭) → **ω_n=30, ζ=0.7 채택**
- 고강성이라 힘 상한 `f_max` 200 → **400 N**

**현재**: `--lamswing --wn 30 --zeta 0.7`. 스윙힘 포화 0.8 %

**한계** ([9/18 Q2](2026-09-18.md)):

- **토크 한계 초과가 전부 여기서 나온다** — stance 0.00 %, **스윙 1.87 % (최대 2.53배)**.
  MuJoCo 가 조용히 잘라내므로 그 순간 명령 ≠ 실현
- **`J̇q̇` 를 무시한다** — 측정하니 **본 항의 69 %** (중앙값 61 %, 상위 10 % 는 150 %).
  "작을 것"이라는 가정이 틀렸고, `mj_jacDot` 은 MuJoCo 3.12 에 **이미 있다**

**다음**: ① `Jᵀ F` 가 관절 한계 안에 들도록 클램프 ② `J̇q̇` 보상 추가 (미검증)

## 4. gait 타이밍 — 최적점은 양쪽에 벽이 있다

**시작**: `T=0.8 s, sf=0.75` → swing 0.2 s

**발전**:

| 시점 | 무엇 | 결과 |
|---|---|---|
| 9/15 (24절) | swing 0.2 s 가 2.6배 격렬함을 `a=6L/T²` 로 규명 → **sf 0.57** | **0.3 → 0.5 m/s 돌파** |
| [9/16 Q6](2026-09-16.md) | 주기를 **늘려봄** (1.0, 1.2 s) | **전부 실패**. 1.2 s 는 제자리도 전도 |
| [9/17 Q1](2026-09-17.md) | 배포 RL 정밀 스윕 (0.05 단위 23점) | **주기는 791 ms 고정**, 바뀌는 건 **sf 0.54 → 0.48** |

> **[정정] 9/17 오전에 내가 "그들은 주기를 524 ms 로 줄인다"고 했는데 틀렸다.**
> 23점 중 21점이 791 ms 동일, cmd 1.00/1.05 두 점만 접촉 채터 아티팩트였다.
> **주기는 우리(800 ms)와 이미 같다.**

**현재**: `T=0.8 s, sf=0.57`. MPC 지평 `N=16 × dt 0.05 = 0.8 s` = 정확히 한 주기

**한계**: sf 가 전 속도에서 고정. 배포 RL 은 속도에 따라 0.54 → 0.48 로 낮춘다

**다음** — **주기는 건드리지 말 것**. 속도 함수로 만들 건 `sf` 뿐:

```
sf(v) = 0.558 − 0.0655·v      R² = 0.967   → [0.50, 0.58] 클램프
이중지지 = 2·sf − 1            (sf < 0.5 면 비행)
```

`sf ≥ 0.50` 클램프면 **비행 없이** 간다. 배포 RL 도 **0.88 m/s 까지 비행 0 %**

> **교훈**: 제약 frame 은 **나쁜 상태를 '합법화'** 해서 양의 되먹임을 만들었다

> **모델과 현실이 어긋날 때 어느 쪽을 고치느냐가 결과를 가른다.**

## 8. SRB 모델 — 왜 '무거운 모델'인가

**시작**: Θ=pelvis 자세, ω=전신 각운동량 역산, p·v=전신 CoM.
**왜 이 조합인지 근거가 흐렸다**

**발전**:

| 시점 | 무엇 | 결과 |
|---|---|---|
| 20절 | MIT vs G1 다리 질량 | 비율은 같으나 **G1 다리가 회전에 2배 영향** (I_yy 1.92배, leg/upper 비 2.54배) |
| 21절 | **상체 SRB 실험** (`11_walk_srb_upper.py`) | **전 변형 패배**. v1 에서 물리 2개 발견 |
| [9/16 Q7](2026-09-16.md) | "이런 조합 쓰는 데가 있나?" | 남들은 안 씀. **단 ω 는 I 와 짝이라 강제** — pelvis ω 정합 버전은 **0.95 s 만에 전도** |
| [9/16 Q8](2026-09-16.md) | ω 불일치 정량화 | pitch 상관 **0.13**, ω(pelvis) 1.317 vs ω(L) 0.070. **다리(0.578)와 상체(0.566)가 상쇄** |
| 9/18 | 21절 재해석 | **그 불일치가 '필터'였다** |

**핵심 이해 — 왜 전신 I·전신 L 이 이기는가**:
다리 43 % 의 스윙 반작용이 상체-회전 모델에선 **전부 비모델 외란**이 된다.
전신 L·I 는 그 반작용을 **L-공간에서 암묵 흡수**한다 — 다리가 앞으로 차면
**전체 L 은 그대로, 분배만 바뀌므로 ω 상태가 요동하지 않는다**.
→ **Θ/ω 불일치는 그 흡수의 '대가'였고, 값을 치를 만한 거래였다.**

v1 에서 얻은 물리 2개:

1. **다리는 wrench 뒤에 전부 매달린다** — `τ = qfrc_bias − JᵀW` 는 접촉력 = W 를
   정확히 실현하므로 stance 다리 무게도 W 가 진다 (`g_eff = g·M_tot/M_ub`).
   **reference 는 bias 를 안 넣어 이 문제가 없다 — bias 유무가 갈림길**
2. **병진은 뉴턴이 정확하다** — `M_tot v̇ = ΣF − M_tot g` 는 다리 포함 근사가 아니다.
   M_ub 를 쓰면 1.76배 과민 → 게인 뻥튀기 → 램프에서 발산

**현재**: 전신 I·전신 L 유지. **근거가 명확해짐**

**한계**: Θ(pelvis) 예측이 사실상 불가 (1스텝 오차가 실제 변화량의 98~113 %)

**다음**: `L_다리` 를 **알려진 아핀항**으로 넣어 Θ̇ 식을 고치는 안
(상관 0.14 → 0.95 검증). 볼록성 유지.
**단 미검증** — 전례상 모델 오차를 고치면 나빠질 수 있다

## 9. 팔 — 지렛대인 줄 알았다가 우선순위 하향

**시작**: 팔 **7.04 kg (21 %)** 가 PD 로 얼어 있음. "활용 안 한 자원" 목록에만 존재

**발전**:

| 시점 | 무엇 | 결과 |
|---|---|---|
| [9/16 Q8](2026-09-16.md) | ω 불일치 원인이 다리↔상체 상쇄 | "팔이 흡수하면 해결" 가설 → **다음 지렛대로 지목** |
| [9/17](2026-09-17.md) | CAM 논문(Lee RA-L 2025) + 권한 실측 | 팔 질량비 **21.1 % vs 논문 22.8 %** 거의 동일. **그런데 축마다 권한이 15배 차이** |
| 9/17 | 배포 RL 계측 | **팔이 아예 없는 12-dof 모델이 1.28 m/s** |

**팔의 CAM 권한** (ω=10 rad/s 기준, 다리 CAM 대비):

| 축 | 덮는 비율 | 제약 포화 | 판정 |
|---|---|---|---|
| roll | **79 %** | 50~63 % | 유망 |
| **pitch** | **40 %** | 58~68 % | **부족** ← Q8 이 노리던 축 |
| yaw | **597 %** | 11~18 % | 권한은 남으나 병목이 작음 |

> 논문이 **수직(yaw) CAM 만 '추종'하고 x,y 는 '감쇠'만** 하는 이유가 이 분포로 설명된다.
> 주의 — 논문 Fig. 5: **CAM 제어 없이 팔을 그냥 풀면 고정 팔보다 나쁘다**

**현재**: 팔 고정 유지.
**1 m/s 이후 주제로 보류** ([ARM_SWING_PLAN.md](../MPC/ARM_SWING_PLAN.md) 에 정정 표시)

**다음** (나중에): RL 이 아니라 **분해운동량 제어**(Kajita 2003) 로.
`q̇_arm = −A_arm⁺·W·(k_G − k̂_G)`, MPC 정식화를 안 건드리므로 볼록성 유지

## 11. 방법론 교훈 — 이 기간에 반복 확인된 것

### ① 닫힌 루프에서 증상을 직접 누르면, 그것이 하중을 받고 있었음이 드러난다 (5회)

| # | 무엇을 눌렀나 | 무슨 일이 | 교훈 |
|---|---|---|---|
| 1 | `--capy` 횡 capture 상한 | pitch 45 % 개선, **roll 악화** | 채택 보류 |
| 2 | LIP 정확식 (중립항 축소) | 유도는 맞는데 **추종 붕괴** | 플래그만 |
| 3 | `td_mode` lp/fz (목표 떨림 제거) | 착지오차 **0.1 cm**, 그런데 **0.5 가 13 초에 붕괴** | 쓸림이 횡 안정화였음 |
| 4 | 제약 frame 정직화 | **발 yaw 31°, roll 65° 전도** | 나쁜 상태를 합법화 |
| 5 | 상체 SRB (모델 경량화) | **전 변형 패배** | 무거운 모델이 필터였음 |

**공통 구조**: 보기 싫은 거동이 사실은 일을 하고 있다.
**옳은 경로는 억제가 아니라 "필요를 줄이는 것"**.

### ② 측정 지표는 단독으로 읽으면 안 된다

- **CoP 포화율**은 반드시 **속도 추종과 함께** ([9/16 Q5](2026-09-16.md)).
  낮은 CoP 는 "여유 있음"일 수도 **"포기함"**일 수도 있다
- **월드 x 속도**는 요 표류가 있으면 과소평가
  ([9/17 Q7](2026-09-17.md): 92 % 를 29 % 로 오독)
- **접촉 전환 검출**은 채터에 취약 (9/17: 주기 791 ms 를 524 로 오독)

### ③ 시험 길이가 결론을 바꾼다

20 초 "통과"가 120 초에선 29.9 초 전도. **완주 판정 최소 120 초** 기준 확립 (9/15)

### ④ 검증은 "존재성"으로 해야 한다

제약 검증의 함정: **"어떤 점힘 배분이 위반한다" ≠ "그 wrench 가 실현 불가"**.
4점 배분은 자유이므로 정답 판정은 **LP 존재성**으로 (18.5절)
