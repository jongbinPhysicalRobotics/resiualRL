# 2026-09-29 (화)

## Q1. 다리 토크 식 — 자코비안을 왜 선속도 · 각속도로 나눴나

**결론:**
- 둘은 같은 식이다: `J = [J_v; J_ω]` (6×5), `τ = Jᵀ[F; M] = J_vᵀF + J_ωᵀM`.
- 나눈 이유 (코드 사실 + 추론):
  - (1) reference C++ 와 MuJoCo `mj_jacSite` 가 jacp · jacr 를 따로 준다.
  - (2) **스윙에서는 나눠야 한다.** 다리가 5 자유도라 6 차원 `J M⁻¹ Jᵀ` 는 계수 5 → 역행렬이 없다.
    그래서 위치 (3) 는 J_v 로 작업공간 제어 (Λ 3×3), 방향은 J_ωᵀ 로 따로 PD 한다 (roll 은 끔 — yaml "MIT humanoid is 5-DOF at the leg").

식 (코드 사실, [leg_control.py](../MPC/src/casadi_mit/leg_control.py)):

| 상태 | 식 |
|---|---|
| 입각 | `τ = J_vᵀF + J_ωᵀM`,  F = −α·u_F,  M = −α·u_M (+ α·m_hold, yaw hold). PD · 중력보상 없음 |
| 스윙 | `τ = J_vᵀ[K_p(p_des − p) + K_d(v_des − v)] + J_vᵀΛ(a_des − J̇_v q̇) + b + J_ωᵀ m_att`,  Λ = (J_v M⁻¹ J_vᵀ)⁻¹ |
| 발 자세 | `m_att = (300 e_pitch − 18 ω_pitch)·ŷ_foot + (305 e_yaw − 18(ω_z − ω_ref))·ẑ` |
| 서기 | `τ(10) = J_vᵀ(−[F_L; F_R]) + J_ωᵀ(−[M_L; M_R])` (6×10) |

문헌:
- Di Carlo (Cheetah) 는 점 발이라 모멘트가 없어 `τ = Jᵀ Rᵀ f` (선속도 자코비안만) 이다.
- OA-MPC 는 `J_c ∈ ℝ^{6×n}`, 반력 u ∈ ℝ⁶ 로 묶어 쓴다.
  저수준은 작업공간 제어기 (TSC, 전신 동역학 `H q̈ + C = S_aᵀτ + J_cᵀu` 를 제약으로 q̈ · τ · u 를 푸는 QP) 로, 우리 (`τ = Jᵀw`) 와 다르다.

## Q2. 스윙 이득 K_p · K_d · 자세 이득은 왜 그 값인가

- 출처 (코드 사실): 모두 reference 설정 파일 값이고, 근거 주석은 없다. 로봇마다 다르다.
  - MIT: ω_n 151 / 151 / 110, K_d 25
  - G1: 100 / 100 / 100, 20 / 20 / 23
  - H1: 600 / 600 / 500, 25 / 25 / 10
- 스윙 자세에서 계산한 의미 (측정, 0.6 m/s 스윙 48 표본 중앙값):

| | x | y | z |
|---|---|---|---|
| 발 끝 겉보기 질량 Λ | 0.82 kg | 0.53 | 4.0 |
| K_p = ω_n²Λ | 18 800 N/m | 12 200 | 48 500 |
| 고유진동수 | 24 Hz | 24 | 17.5 (스윙 한 번에 3 ~ 4 주기) |
| **감쇠비 ζ = K_d / (2Λω_n)** | **0.10** | **0.16** | **0.03** |

- (추론) K_p 를 Λ 로 맞춰 방향마다 같은 빠르기로 반응하게 한 것은 표준 작업공간 설계다.
  K_d 는 고정값이라 감쇠가 매우 약하다 (임계감쇠엔 250 / 160 / 880 필요). 추종은 주로 가속도 앞먹임이 맡는 것으로 본다.
- 발 자세 (측정):

  | | 유효 회전 관성 | 고유진동수 | ζ | 34 N·m 에 걸리는 오차 |
  |---|---|---|---|---|
  | yaw | 0.042 kg·m² | 13.5 Hz | 2.5 | **6.4°** |
  | pitch | 0.032 | 15.5 Hz | 2.9 | 6.5° |

  → 작은 오차를 붙잡는 용도의 이득이다. 37° 를 한 번에 목표로 주면 포화한다 (Q3 과 맞물림).

## Q3. 스윙 발 yaw 를 궤적으로 (9/28 Q13 추천 1 번) — 토크 포화가 사라지고, 두 후보 모두 선행과 무관하게 전 목표 완주

사용자 결정 (9/29): Q13 다음 후보 중 1 번 (스윙 발 방향을 궤적으로 계획) 부터 한다.

### 1. 무엇을 바꿨나 (변형, 기본값 = reference)

- reference ([leg_control.py](../MPC/src/casadi_mit/leg_control.py) `swing_attitude_torque`): 착지 yaw ψ_td 를 이륙 순간부터 목표로 준다.
  `m_z = 305·(ψ_td − ψ_foot) − 18·ω_z,leg`. 이륙 순간 오차 ≈ 37° → 약 200 N·m 명령 (한계 34).
- **`yawtraj=f`** ([controller.py](../MPC/src/casadi_mit/controller.py) `_mark_liftoff_yaw` · `_swing_yaw_ref`):
  이륙 순간 발 yaw ψ_lo 에서 ψ_td 까지 스윙 시간 × f 동안 최소 저크 곡선으로 보간한다.
  ```
  ψ_des(s) = ψ_lo + Δ·(10s³ − 15s⁴ + 6s⁵),   ψ̇_des = Δ·(30s² − 60s³ + 30s⁴)/T,   Δ = wrap(ψ_td − ψ_lo)
  m_z = 305·(ψ_des − ψ_foot) − 18·(ω_z,leg − ω_ref)
  ```
- **`yawff`** — 속도 목표 ω_ref (ω_z,leg 는 다리 관절에 의한 몸통 기준 회전):

  | yawff | ω_ref | 뜻 |
  |---|---|---|
  | 0 | 0 | 위치만 보간 |
  | 1 | ψ̇_des − **실측** 몸통 ω_z | 몸통 흔들림이 목표에 섞임 |
  | **2** | ψ̇_des − **명령** ψ̇ | 직진이면 reference 와 같고, 회전이면 예정된 몸통 회전만 뺌 |

- 같이 넣은 키: `yawkp` · `yawkd` (스윙 yaw 이득).
